## Question

What does composing a message look like, on both platforms?

This is the second half of the original gripe. Decide:
- Where the composer lives in forum mode versus chat mode.
- How starting a **new topic** works — easy and inline in forum mode, tucked in a menu elsewhere, per the brief.
- How the destination (channel + topic) is displayed and changed mid-compose.
- Markdown affordances: preview, formatting controls, mention and emoji autocomplete.
- Reply, quote-reply, and attachment entry points.
